# 🚀 Landing Page - Gabrielle Janine | Experiências Digitais

Landing page profissional desenvolvida para apresentar o portfólio, serviços e soluções digitais criadas por Gabrielle Janine. O projeto foca em design limpo, interatividade via JavaScript, segurança e alta responsividade.

## 🛠️ Tecnologias e Recursos Utilizados

* **HTML5**: Estruturação semântica da página.
* **CSS3**: Estilização avançada, Flexbox, Animações (`@keyframes`), Pseudo-classes (`:hover`, `:focus`) e Responsividade (`@media queries`).
* **JavaScript (ES6+)**: Manipulação de DOM para o botão interativo de troca de tema de fundo.
* **EmailJS API**: Integração para envio direto dos dados do formulário de contato para o e-mail pessoal sem necessidade de backend próprio.
* **Google reCAPTCHA**: Camada de segurança contra robôs e spam no formulário.

## 📱 Responsividade
O site é totalmente adaptado para diferentes resoluções de telas através de media queries, oferecendo uma excelente experiência de navegação em computadores, tablets e smartphones.

## 🔧 Como Executar o Projeto

1. Clone ou baixe este repositório em sua máquina.
2. Abra a pasta do projeto em seu editor de código (ex: **VS Code**).
3. Abra o arquivo `index.html` diretamente em seu navegador web favorito ou utilize a extensão **Live Server** para visualizar em tempo real.
